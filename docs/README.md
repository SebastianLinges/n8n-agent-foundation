# Dokumentation

Dieser Ordner beschreibt Import, Sicherheit, Architektur und Betrieb des RWG Teams Agents.

## Dokumente

| Datei | Inhalt |
|---|---|
| `import-and-security.md` | Import in n8n, erforderliche Credentials, Sicherheitsregeln |
| `workflow-overview.md` | Fachlicher Ablauf, Kernfunktionen, Grenzen |
| `architecture.md` | Technische Architektur des Projekts |
| `conventions.md` | Namens- und Ablagekonventionen |
| `knowledge-strategy.md` | Strategie fuer Wissensbasis und RAG |
| `project-foundation.md` | Urspruengliche Projektbasis und Ordnerstruktur |

## Reihenfolge fuer neue Mitwirkende

1. `import-and-security.md`
2. `workflow-overview.md`
3. `architecture.md`
4. `knowledge-strategy.md`

## Pflege

Wenn sich der Workflow aendert, muss mindestens `workflow-overview.md` geprueft werden. Wenn sich Credentials, Import oder Sicherheitsregeln aendern, muss `import-and-security.md` angepasst werden.
