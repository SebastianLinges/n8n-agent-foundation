# Knowledge Base

Dieser Ordner ist fuer Wissensinhalte vorgesehen, die spaeter in eine RAG-Strecke ueberfuehrt werden koennen.

## Dateien

| Datei | Inhalt |
|---|---|
| `sample-knowledge.md` | Beispielhafte Wissensdatei |

## Zweck

Die produktive Wissenssuche im Workflow laeuft ueber Supabase `document_chunks`. Dateien in diesem Ordner sind daher primaer Quelle, Muster oder Dokumentation fuer Inhalte, die in den Vector Store uebernommen werden.

## Regeln

- Keine Zugangsdaten oder geheimen internen Informationen ablegen.
- Quellen, Gueltigkeit und fachliche Verantwortung moeglichst dokumentieren.
- Inhalte klar strukturieren, damit Chunking und Retrieval spaeter bessere Treffer liefern.
