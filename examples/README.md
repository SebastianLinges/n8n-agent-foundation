# Beispiele

Dieser Ordner enthaelt Testdaten und Beispielnachrichten fuer lokale Pruefungen.

## Dateien

| Datei | Inhalt |
|---|---|
| `example-chat-input.json` | Beispiel fuer ein Teams Chat Event |

## Nutzung

Beispiele helfen beim Verstehen der erwarteten Eingangsdaten. Sie ersetzen keinen echten n8n Testlauf, weil Microsoft Teams und Graph API je nach Nachrichtentyp unterschiedliche Felder liefern koennen.

## Regeln fuer Beispiele

- Keine echten personenbezogenen Daten verwenden.
- Keine Tokens, Credential-IDs oder privaten URLs committen.
- Beispiele klein halten und auf den jeweiligen Testfall fokussieren.
